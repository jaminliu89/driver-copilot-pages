# Driver Copilot／司机收益副驾 PRD
版本：0.1，2026年09月08日。状态：实现合同；尚未获得真实司机可用性和收益效果验收。

## 1．目标与原始意图
新来西安的司机不熟悉城市，空等、空驶、低价订单和奖励口径会掩盖真实时间成本。产品应把复杂判断压缩成一个行动，让司机减少无效工时，保留生活与其他工作的时间。不是订单计算器，不让司机录入分析数据，不把司机当实验员。
当前用户授权链：Mermaid → 多页低保真 → PRD → 实现 → 测试修复 → GitHub Pages。原型先于本 PRD 保存；工程实现承接原型。原对话 ID：6a9a3154-9674-83ea-8425-2e0b59cf34dd。

## 2．用户故事与成功标准
作为陌生城市司机，我打开首页就看到当下的一个动作与理由，不必先上传数据。
作为停车后的司机，我可分享/选择截图让系统自动区分行程和奖励，不手算、不填表。
作为担心耗时的司机，我能看见休息和会话计时，但它不会冒充平台在线工时。
作为团队研究人员，我在内部验证听单策略和区域策略，不让司机填 benchmark。
作为数据不足的使用者，我能知道哪些建议是参考、哪些数据已经过期，避免误把预测当保证。

工程标准：首屏零分析输入；导航最多两次到达五核心页面；每个行动有理由、级别与数据时效；离线可打开；金额用整数分；重复截图不重复累计；所有私人记录留在本机。
用户结果标准（待实测）：5名司机安全停车后，至少4名能在5秒内说出当前行动，至少4名区分参考建议与实时证据；7天观察空等时长、总占用工时、净收益变化。不能以自动 UI 测试替代这些标准。

## 3．版本范围
本轮 P0：独立静态 PWA、五核心页面＋城市事件＋设置、可点击低保真、决策与收入领域模块、本机 OCR 与预览确认、IndexedDB、隐私清除、安装、离线、驾驶大字模式、内部研究工具、测试与发布。
真实接入：本机上海时区时间；浏览器授权定位，仅前台；西安固定城市坐标的公开天气模型请求（个人非商业试用）；用户自选截图本机 OCR。
待授权／待证据：享道官方账户同步、精确路况、航班/铁路实时接口、城市活动 feed、完整成本/订单状态/在线时长、实测区域收益。无这些数据不能声称零输入自动同步或个性化收益优化已完成。
禁止：抢单外挂、模拟点击平台、虚拟定位、逆向账号、截取其他 App 私有数据、后台持续 GPS、自动打开听单开关、付费订阅、CRM、原生 App。

## 5．五行动合同与优先级
输出结构：action（run/change/rest/adjust/withdraw 或 null）、title、reason、basis（reference/verified/unavailable）、updatedAt、expiresAt。
安全与数据门禁优先于收益。驾驶模式只显示大字与回停车入口；前台 GPS 有速度且超过2.8m/s时切驾驶模式，不能把没有速度当已停车。平台履约始终优先，所有移动建议都必须在当前服务完成后且安全时执行。
基础参考：上海时区午间12–15点可显示“休”的时段参考；收工晚间显示“调”的顺路设置检查；其他白天显示“跑”的保持当前安排参考。早晚高峰仅是城市作息假设，不声称享道供需已验证。深夜建议休息，不鼓励追目标。
“换”：只有有效期内、区域与城市一致、来源明确、已验证且改善超过转移成本的证据才允许；本轮无此生产数据。
“撤”：只有有效期内、区域一致、明确风险证据才允许；本轮无此生产数据。
内部回放覆盖五动作，但示例结果绝不进入生产。
位置未授权/精度不足/过期时显示西安参考范围。已知位置不在西安时不给当地策略，显示未支持城市；不自动假装用户在西安。
时段切换每分钟重新计算。网络离线时展示本机时段参考，天气超过30分钟不用于建议；定位超过5分钟不用。错误不能引起策略反复跳动。

## 6．享道数据字典与口径
金额整数分。保存 sourcePage、sourceLabel、period、periodPrecision、capturedAt、recognizedAt、confidence、fields、reconciliation、contentKey。日期有年则保存年；截图仅“9.8”时保留月日，不偷偷补当前年。无法识别周期的快照不允许保存成某一天。
| 字段 | 定义 | 本次截图证据 |
|---|---|---|
| trip | 页面列示行程收入 | 日48.24；月558.51 |
| reward | 奖励，包含免佣卡奖励与接驾补偿奖等平台归类 | 日14.71；月104.38 |
| addition | 页面增项，语义以平台说明为准 | 日/月0.00 |
| deduction | 页面扣减，以正数保存，参与核对时减去 | 日0.00；月页未显示，存null |
| valueAdded | 页面增值，不推断具体服务 | 日/月0.00 |
| displayedIncome | 日收入/今日收入页的总额 | 62.95 |
| platformTurnover | 平台原名“流水”的页面数 | 今日35.75；9月总流水662.89 |
| netIncome | 总收入扣实际运营成本后的净额 | 未知，不从截图推导 |
| onlineDuration | 官方记录的在线时长 | 未知，不从截图首末订单时间计算 |

日收入核对：48.24＋14.71＋0−0＋0＝62.95。奖励占已显示收入23.4%。
日流水35.75与日收入62.95差额27.20，仅为展示差额；原因未证实，不能称抽佣或成本。
月流水662.89＝558.51＋104.38＋0＋0，奖励占月流水15.7%；月页没有扣减字段，不能填0，也不能据此定义所有平台流水都包括奖励。
月44单是页面显示总订单。662.89÷44≈15.07只可称月页总额/显示单量，非单笔净收益；第一版不把它作为派单策略证据。
日行程明细：15.37＋8.83＋11.83＋12.21＝48.24。
日奖励明细：3.02＋11.49＋0.20＝14.71。0.20接驾补偿在奖励页，所以归reward而非addition。
汇总截图、明细截图、行程/奖励筛选截图可能覆盖相同交易，不能互相相加。第一版以快照为单位保存，明细页仅用于识别和验证，不强行推断未知全量。

## 7．OCR、去重与持久化
停车后可选图片；接受JPEG/PNG/WebP且不超过12MB，单次一张。使用本机 Tesseract.js 简体中文＋英语，worker/core/语言文件同站托管，按需加载；首次 OCR 需要下载较大资源。无私有截图上传 API。
可识别本次六种享道页面：今日数据、月流水、日收入汇总、全部明细、行程明细、奖励明细。兼容页标签间空白；保留OCR不确定性。
解析以标签与金额关系为依据，不只匹配固定截图数字。完整日汇总必须总分核对；残缺、周期不明、低置信或不一致时不保存。用户只需确认或重选，不要求修数字。
主键为周期＋页面口径＋规范化金额对象的稳定语义键；同一快照重复导入不重复保存。变动快照作为不同时间版本，收入页不累加快照。不同浏览器存储隔离，没有账号同步。
文件原图在读取后释放，仅结构化字段落库；共享临时图进入本机IDB后读取即删；失败/取消也可清除。数据库不可用时显示明确错误，不能显示“已保存”。删除后刷新仍为空。

## 8．PWA 与发布
ES modules，无前端框架或服务端；相对路径支持 /Mobility-Lab/ 子路径。Service Worker 只缓存本产品白名单，不删除同源其他产品缓存。App Shell完整首次在线访问后可离线打开；天气网络优先、超时降级；OCR资产按需缓存。
Manifest 有192/512图标、standalone、相对scope/start_url与share_target。支持的安装浏览器通过SW接收POST图片，本机保存后303跳转收入页；不支持分享入口的平台用文件选择。iOS需Safari添加主屏幕，Android需浏览器安装。桌面浏览器模拟不等于真机安装验收。
发布产物仅driver运行文件、公开设计文档、依赖许可证；排除研究目录、测试、个人截图和原对话。GitHub Pages源码仓仍可能公开，不能拿“目录隐藏”当鉴权。
回滚：以此前driver版本构建相同产物并正常提交；缓存随内容哈希换版。首次上线无旧driver版本，可停止Pages发布；不得force push或覆盖既有Mobility Lab代码。

## 10．内部实验与运行责任
当前Codex为实现和交付执行者；独立代码/界面审查单独委派；尚无实名实地研究运营者，不虚构CPO或司机参与。
团队实验：特惠优选开关、机场主动进入与不进入、北站等待与退出、午间跑与休息。先取得合法数据接入和参与者同意；按司机/日期/天气分层随机或配对，固定观察窗，记录奖励与成本、选择偏差和不确定区间。不得用预设指数100/82充当结论。
北极星为扣完整成本后的每占用小时贡献与释放工时；护栏为总净现金、疲劳、空驶。任何样本不足、成本缺失或混入demo都不能发布“增收策略”。
本轮免费个人试用，无后台常驻、无自动实验、无付费调用。公开天气服务商使用条款与可用性独立于代码；商业化前复核授权。
上线后可见状态与错误由设备显示；本轮不安装监控调度器。真实用户7日复查为待安排事项，不称已启动持续监控。
